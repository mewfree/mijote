#+title: mijote
#+description: A keyboard-driven TUI orchestrator for the coding agents you already pay for

mijote runs several coding agents side by side (Claude Code, Gemini CLI,
Codex...) behind one interface: shared sessions, isolated git worktrees,
one place to review diffs and approve tool calls.

It does *not* replace the agents. Each backend spawns the official CLI, so your
existing subscriptions, logins and quotas keep working untouched.

* status

Early scaffold. See =project.org= for the plan.

* usage

#+begin_src sh
mijote            # open the TUI
mijote agents     # list backends
mijote install claude
mijote ask claude "explain this repo"
#+end_src

Keys: =n= new session (own worktree), =N= new session in the current
directory/branch, =d= close it, =j=/=k= switch, =i= prompt, =Enter= send,
=Esc=/=Ctrl-c= cancel a running turn, =q= quit. Permission requests pop up as
a modal: =1-9= choose, =Esc= rejects.

By default each session runs in its own git worktree and branch (=mijote/<agent>-<n>=),
stored under =~/.local/share/mijote/worktrees=. Untouched worktrees are deleted
when the session closes; ones with changes are kept and reported.

* build

#+begin_src sh
make run ARGS=agents
make test
#+end_src

* design

- *orchestrator*: the agent loop, tools and model access
  stay in the vendor CLIs.
- *transport*: Agent Client Protocol (ACP) over stdio, via each agent's native flag or adapter.
- *isolation*: one git worktree per task, so agents never step on each other.
- *ux*: ratatui TUI, keyboard first.
