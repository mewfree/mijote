#+title: mijote
#+description: A keyboard-driven TUI orchestrator for the coding agents you already pay for

mijote runs several coding agents side by side (Claude Code, Codex,
Antigravity...) behind one interface: shared sessions, isolated git worktrees,
one place to review diffs and approve tool calls.

It does *not* replace the agents. Each backend spawns the official CLI, so your
existing subscriptions, logins and quotas keep working untouched.

[[file:demo.gif]]

* status

Early but usable: the TUI, ACP transport, session persistence, model
selection and per-session worktrees work. Still open: ACP authentication,
resuming agent context, and a review/merge flow for session branches. See
=project.org= for the plan.

* usage

#+begin_src sh
mijote            # open the TUI on a new session in the current directory
mijote --resume   # reopen saved sessions for this directory
mijote agents     # list backends
mijote install claude
mijote ask claude "explain this repo"
#+end_src

Bare =mijote= starts a session in the current directory using the last-used
agent (falling back to the first installed backend).

** keys

The prompt is a vim-style editor: =i= / =Enter= insert, =Esc= back to normal,
=Enter= send, =Shift-Enter= (or =Alt-Enter=, =Ctrl-J=) newline, =Up=/=Down= (and
=k=/=j= in normal mode) for prompt history at the first/last line. Normal mode
has motions (=h l j k 0 ^ $ w b e gg G=), operators (=d c y= + motion), =x p u
Ctrl-r= and counts. Bracketed paste works in insert mode; pastes over 3 lines
or 500 characters collapse to a =[Pasted text #1 +N lines]= placeholder and
expand on send.

App commands sit behind a leader, =Space= in normal mode or =Ctrl-a= anywhere
(no leader needed while no session is open):

| key         | action                                            |
|-------------+---------------------------------------------------|
| =n=         | new session in its own worktree                   |
| =N=         | new session in the current directory and branch   |
| =d=         | close session                                     |
| =s= / =Tab= | floating session switcher (=j/k=, =1-9=, =Enter=) |
| =j= / =k=   | next / previous session                           |
| =g= / =G=   | top / bottom of transcript (also =Home= / =End=)  |
| =M=         | model picker (also =/model= in the prompt)        |
| =e=         | effort picker (also =/effort= in the prompt)      |
| =t=         | toggle thoughts & tool details (also =Ctrl-o=)    |
| =m=         | toggle mouse capture                              |
| =q=         | quit                                              |

=Ctrl-c= cancels a running turn (or quits when idle); =Ctrl-d= quits
immediately from any mode. Permission requests pop up as a modal: =1-9= choose,
=Esc= rejects. Scroll with the wheel, PgUp/PgDn or leader + arrows; drag with
the mouse to select transcript text, which is copied to the clipboard on
release. Sessions are saved under =~/.local/share/mijote/sessions= and can be
reopened (transcript only) with =mijote --resume=. =Shift-Enter= needs a
terminal with the kitty keyboard protocol.

On startup, =mijote= opens a session directly in the current directory (same as
=leader + N=). Use =leader + n= to start a session in its own git worktree and
branch (=mijote/<agent>-<n>=) under =~/.local/share/mijote/worktrees=;
untouched worktrees are deleted on close, while ones with changes are kept and
reported.

* build

#+begin_src sh
make run ARGS=agents
make test
#+end_src

* design

- *orchestrator*: the agent loop, tools and model access
  stay in the vendor CLIs.
- *transport*: Agent Client Protocol (ACP) over stdio, via each agent's native flag or adapter.
- *isolation*: one git worktree per task, so agents never step on each other.
- *ux*: ratatui TUI, keyboard first, vim-style prompt editing.
- *persistence*: one JSON record per session; the agent restarts cold behind the old transcript.
