#+title: mijote – Project Tasks
#+description: TUI orchestrator for existing coding-agent subscriptions

* Decisions

** DONE Orchestrator, not a harness
Reusing subscriptions means driving the official CLIs. Writing our own agent loop would force API-key billing and lose vendor tuning. We own the UX, sessions and worktrees; vendors own the loop.

** DONE Antigravity entry point
Community adapter =antigravity-acp= wraps the =agy= CLI over ACP. Works technically; ToS risk noted above.

* Tasks

** DONE Scaffold crate, Makefile, readme.org, project.org
** DONE ACP client over stdio
=src/agent/acp.rs=: spawn, =initialize=, =session/new=, =session/prompt= with streamed =session/update= events and =session/request_permission= callbacks. Tested against a scripted fake agent; real handshake verified against =gemini --experimental-acp=. Try it with =mijote ask <agent> "<prompt>"=.
** TODO ACP: authentication
=session/new= against gemini fails with 401 until the CLI is logged in. Handle =authMethods= from =initialize= and call =authenticate=, or surface a clear "log in with the CLI first" message.
** TODO ACP: cancel, load/resume, set_mode
=session/cancel= needs a non-blocking prompt loop (comes with the TUI event loop). Then =session/load= and =session/set_mode=.
** DONE Managed adapter install
=src/agent/install.rs=: resolves an agent binary from PATH or =$MIJOTE_HOME= (default =~/.local/share/mijote=), otherwise =npm install --prefix= of a pinned adapter version (claude: =@agentclientprotocol/claude-agent-acp=, codex: =@agentclientprotocol/codex-acp=). =mijote install <agent>= does it explicitly; =mijote ask= does it on first use. Requires Node/npm. Verified: =mijote ask claude= completes a real turn.
** TODO Verify codex and antigravity end to end
Exercise =codex-acp= (needs Codex login or API key). Antigravity stays manual (Bun or prebuilt binary + =agy=); Google's ToS prohibits third-party access with personal accounts.
** TODO Adapter updates
Pinned versions drift. Add =mijote update= (or a version check) and decide how to handle a missing Node (download a managed runtime?).
** TODO Stream-JSON fallback transport (only if an agent lacks an ACP adapter)
For CLIs without ACP (=claude -p --output-format stream-json=, =codex exec --json=).
** DONE Session persistence
=src/store.rs=: one JSON record per session under =$MIJOTE_HOME/sessions/= (agent, cwd, worktree, transcript), written atomically after each prompt and turn end and on quit. On start, records for the current directory are reopened with a fresh agent behind the old transcript (a notice says the agent does not remember it). Closing with =d= deletes the record; quitting keeps it. A missing worktree falls back to the current directory.
** TODO Resume agent context on restore
Persisted sessions restart the agent cold. Store the ACP session id and use =session/load= when the agent advertises =loadSession=. Also: restored sessions spawn their agents eagerly at startup; make that lazy (first prompt) so reopening many sessions does not launch many CLIs.
** DONE Model selection
=ModelState= in =src/agent/acp.rs= reads the model from =session/new=: the =configOptions= entry with category =model= (what =claude-agent-acp= sends; switched with =session/set_config_option=, announced by =config_option_update=), falling back to the older =models= field (=session/set_model=, =current_model_update=). The header shows the current model, =M= (normal mode, between turns) opens a picker, and each change is logged as a transcript notice. The choice is stored in the session record and re-applied on restore. Agents that advertise no models get a "does not offer model selection" message. Unit-tested against fake agents; the config-option shape was taken from the pinned =claude-agent-acp= source, not a live run. Codex and Gemini not checked.
** DONE Slash commands: /model
Insert-mode =/model= opens the model picker; =/model <name>= switches directly (id or display name, case-insensitive; unknown names list the choices). Handled locally in =App::slash_model= because =/model= is a terminal-UI command in Claude Code and not reliable to forward. Anything else, including =/models=, goes to the agent as a prompt.
** TODO Slash commands: agent-advertised
Parse =available_commands_update= (today =Event::Other=) so the agent's own commands can be listed and completed in the prompt box; =/model= should then appear alongside them.
** TODO Session model: tasks and history browser
Task -> session(s) grouping, and a way to list and reopen records saved from other directories or closed sessions.
** DONE Git worktree per task
=src/worktree.rs=: each session gets branch =mijote/<agent>-<n>= in a worktree under =$MIJOTE_HOME/worktrees/<repo>/=, based on the repo's =HEAD=. Outside a git repo (or with no commits) the session falls back to the current directory with a notice. On =d= close or quit, an untouched worktree and branch are deleted; one with changes or commits is kept and reported. Shells out to =git=. Verified in a pty against a real repo.
** DONE Worktrees: optional
=n= opens the picker for an isolated session (worktree, as before); =N= opens it for a session that runs directly in the current directory and branch (no worktree, nothing to clean up). Picker title says which. Still TODO: a config default once =src/config.rs= exists.
** TODO Worktrees: review and merge flow
Show the session branch's diff/commits in the TUI; actions to merge, cherry-pick, open a PR, or discard. Today kept branches are only reported on close.
** TODO Worktrees: start from the dirty tree (optional)
Worktrees branch from =HEAD=, so uncommitted work in the main checkout is invisible to the agent. Offer =git stash create= as the base, or warn when the main tree is dirty.
** TODO Worktrees: crash cleanup and hung agents
A crashed mijote leaves worktrees behind (=mijote cleanup= / =git worktree prune=). Closing waits for the agent thread; a hung agent keeps its worktree (safe, but never reported).
** DONE TUI shell (ratatui)
Sidebar of sessions, transcript pane, prompt line, permission modal, new-session picker (=n=). One worker thread per session owns its ACP client; =session/cancel= goes through a =CancelHandle= so it works mid-turn. Files: =src/app.rs= (state, keys), =src/ui/mod.rs= (rendering), =src/session.rs= (model + worker). Verified in a pty against a real Claude turn.
** DONE TUI: visual redesign
=src/ui/mod.rs= only. Palette constants (ANSI accent, one 256-colour grey); sidebar of two-row session cards (status glyph, agent, branch or live state, accent bar on the selection) with a wordmark and key footer; header strip with agent, branch and status; transcript without a box, hand-wrapped so every line keeps its gutter (user =▎=, thoughts =┊=, code fences =▏=, tool calls =✓ ✗ ○= grouped without gaps); rounded prompt box with placeholder; NORMAL/INSERT/PICK badge and bold-key hints in the status bar; rounded modals with hints on the bottom edge; welcome screen. =locate= follows the new geometry (cards are 2 rows, 2-row head).
** TODO TUI: multi-line input and editing
Prompt box is single-line, append-only. Use tui-textarea (as rugit does): cursor movement, multi-line, paste.
** TODO TUI: markdown rendering and tool call detail
Render agent markdown/code blocks; expand tool call content and diffs (=tool_call_update.content=).
** TODO TUI: rename sessions, show worktree state
=d= closes (done); still want rename, and live dirty/ahead counts per session in the sidebar.
** DONE TUI: mouse mode
Mouse capture is on by default: wheel scrolls the transcript, a click on a sidebar row selects that session, a click on the prompt box enters insert mode. =m= (normal mode) toggles capture off so the terminal's own text selection works. Hit-testing lives in =ui::locate= beside the layout; modals (picker, permission, confirm) ignore the mouse.
** TODO TUI: transcript scrolling and search
Only PgUp/PgDn today; add half-page, =g=/=G=, =/= search.
** TODO TUI: open the picker when there is no session
Don't auto-spawn: an agent must be chosen and spawning launches/installs an external CLI. Instead (1) with no sessions at startup, open the picker directly; (2) =i=/=Enter= with no sessions opens the picker (currently a silent no-op in =handle_normal=); (3) if =open_picker= yields exactly one agent, spawn it directly and skip the picker.
** DONE TUI: Ctrl-D quits
=Ctrl-D= sets =should_quit= from any mode, ahead of the permission modal (same path as idle =Ctrl-C=). Conflicts with the planned =Ctrl-u/d= half-page scroll in the vim task; resolve there.
** DONE TUI: working indicator
Running turns show an animated spinner in the sidebar and a trailing =working… 12s= line in the transcript (=Session.turn_started=); a pending permission shows =waiting for your permission=. A long silent turn no longer looks hung.
** DONE TUI: confirm destructive actions
=q= (while any agent is mid-turn) and =d= (running or non-empty session) open a y/n confirm modal. Normal-mode =Esc= no longer cancels the turn; use =Ctrl-C=. =Ctrl-D= still quits immediately.
** DONE TUI: context-aware status bar
Key hints depend on state (idle, running, scrolled, insert, confirm); cwd is shown only when it fits.
