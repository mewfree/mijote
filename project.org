#+title: mijote – Project Tasks
#+description: TUI orchestrator for existing coding-agent subscriptions

* Decisions

** DONE Orchestrator, not a harness
Reusing subscriptions means driving the official CLIs. Writing our own agent loop would force API-key billing and lose vendor tuning. We own the UX, sessions and worktrees; vendors own the loop.

** DONE Antigravity entry point
Community adapter =antigravity-acp= wraps the =agy= CLI over ACP. Works technically; ToS risk noted above.

* Tasks

** DONE Scaffold crate, Makefile, readme.org, project.org
** DONE ACP client over stdio
=src/agent/acp.rs=: spawn, =initialize=, =session/new=, =session/prompt= with streamed =session/update= events and =session/request_permission= callbacks. Tested against a scripted fake agent; real handshake verified against =gemini --experimental-acp=. Try it with =mijote ask <agent> "<prompt>"=.
** TODO ACP: authentication
=session/new= against gemini fails with 401 until the CLI is logged in. Handle =authMethods= from =initialize= and call =authenticate=, or surface a clear "log in with the CLI first" message.
** TODO ACP: cancel, load/resume, set_mode
=session/cancel= needs a non-blocking prompt loop (comes with the TUI event loop). Then =session/load= and =session/set_mode=.
** DONE Managed adapter install
=src/agent/install.rs=: resolves an agent binary from PATH or =$MIJOTE_HOME= (default =~/.local/share/mijote=), otherwise =npm install --prefix= of a pinned adapter version (claude: =@agentclientprotocol/claude-agent-acp=, codex: =@agentclientprotocol/codex-acp=). =mijote install <agent>= does it explicitly; =mijote ask= does it on first use. Requires Node/npm. Verified: =mijote ask claude= completes a real turn.
** TODO Verify codex and antigravity end to end
Exercise =codex-acp= (needs Codex login or API key). Antigravity stays manual (Bun or prebuilt binary + =agy=); Google's ToS prohibits third-party access with personal accounts.
** TODO Adapter updates
Pinned versions drift. Add =mijote update= (or a version check) and decide how to handle a missing Node (download a managed runtime?).
** TODO Stream-JSON fallback transport (only if an agent lacks an ACP adapter)
For CLIs without ACP (=claude -p --output-format stream-json=, =codex exec --json=).
** TODO Session model and persistence
Task -> session(s) -> transcript, stored under the XDG data dir.
** TODO Git worktree per task
Create/cleanup worktrees; branch naming; never touch the user's main checkout.
** DONE TUI shell (ratatui)
Sidebar of sessions, transcript pane, prompt line, permission modal, new-session picker (=n=). One worker thread per session owns its ACP client; =session/cancel= goes through a =CancelHandle= so it works mid-turn. Files: =src/app.rs= (state, keys), =src/ui/mod.rs= (rendering), =src/session.rs= (model + worker). Verified in a pty against a real Claude turn.
** TODO TUI: multi-line input and editing
Prompt box is single-line, append-only. Use tui-textarea (as rugit does): cursor movement, multi-line, paste.
** TODO TUI: markdown rendering and tool call detail
Render agent markdown/code blocks; expand tool call content and diffs (=tool_call_update.content=).
** TODO TUI: close/rename sessions, per-session cwd
=d= to close a session (kills the agent); show the cwd/branch per session. Pairs with the worktree task.
** TODO TUI: transcript scrolling and search

** TODO Parallel runs and cross-agent comparison
Same prompt to N agents, compare resulting diffs.
