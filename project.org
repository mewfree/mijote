#+title: mijote – Project Tasks
#+description: TUI orchestrator for existing coding-agent subscriptions

* Decisions

** DONE Orchestrator, not a harness
Reusing subscriptions means driving the official CLIs. Writing our own agent loop would force API-key billing and lose vendor tuning. We own the UX, sessions and worktrees; vendors own the loop.

** DONE Antigravity entry point
Official =agy= CLI ships a native ACP stdio server (=agy acp=), configured with =Install::None= in =src/agent/mod.rs= (no third-party adapter). Verified end to end with =mijote ask antigravity= and =session/set_config_option= model switching.

** DONE Remove Gemini CLI backend
Removed the =gemini= entry from =agent::KNOWN= in =src/agent/mod.rs= now that Antigravity (=agy acp=) is supported. Updated =readme.org=, =demo-setup.sh=, and the switcher test in =src/app.rs=.

=src/store.rs=: one JSON record per session under =$MIJOTE_HOME/sessions/= (agent, cwd, worktree, transcript), written atomically after each prompt and turn end and on quit. ** DONE Model selection
=ModelState= in =src/agent/acp.rs= reads the model from =session/new=: the =configOptions= entry with category =model= (what =claude-agent-acp= sends; switched with =session/set_config_option=, announced by =config_option_update=), falling back to the older =models= field (=session/set_model=, =current_model_update=). The header shows the current model, =M= (normal mode, between turns) opens a picker, and each change is logged as a transcript notice. The choice is stored in the session record and re-applied on restore. Agents that advertise no models get a "does not offer model selection" message. Unit-tested against fake agents; the config-option shape was taken from the pinned =claude-agent-acp= source, not a live run. Codex and Gemini not checked.

Handled locally in =App::slash_model= because =/model= is a terminal-UI command in Claude Code and not reliable to forward. Anything else, including =/models=, goes to the agent as a prompt.
** DONE Model effort level
=EffortState= / =EffortInfo= in =src/agent/acp.rs= parses the ACP =thought_level= config option from =configOptions= (matching =category: "thought_level"= or fallback ids =thought_level= / =effort= / =reasoning_effort=, supporting flat and grouped options plus descriptions) and switches it via =session/set_config_option=. =AcpClient::set_model=, =AcpClient::set_effort=, and =config_option_update= (=Event::ConfigOptionsUpdated=) all reconcile both model and effort state so switching to a model with different or no effort levels updates or clears the picker cleanly. =src/session.rs= and =src/store.rs= persist =effort= (backwards-compatible via =#[serde(default)]=) and re-apply model then effort on restore. In the TUI (=src/app.rs=, =src/ui/mod.rs=), the header displays =· effort: <name>=, =leader + e= opens the effort picker modal (=Mode::Effort=), =/effort= / =/effort <level>= works locally in insert mode, and =mijote ask --effort <level>= sets effort before prompting.
** DONE Slash commands: agent-advertised

In =src/app.rs= and =src/ui/mod.rs=, typing a leading =/= in insert mode opens a floating autocomplete popup (=SlashPopup= / =render_slash_popup=) above the prompt box listing local built-ins (=/model=, =/effort=, tagged =local=) alongside deduplicated agent-advertised commands with fuzzy name and description matching, live updates when commands arrive, =↑/↓= or =C-p/C-n= navigation, =Tab= completion, =Enter= to run (or complete args when a command advertises an =input.hint= on a prefix match), and =Esc= to dismiss.
** DONE Prompt: =@= file mentions

Typing =@= in insert mode opens a floating autocomplete popup above the prompt box (=↑/↓= or =C-p/C-n= to move, =Tab=/=Enter= to insert, =Esc= to dismiss). =AcpClient::initialize= reads =agentCapabilities.promptCapabilities.embeddedContext= and =session.rs= / =mijote ask= send small UTF-8 files as ACP =resource= blocks when supported, falling back to =resource_link= for larger/binary files or agents without =embeddedContext= (leaving non-existent =@tokens= untouched as plain text).

On =d= close or quit, an untouched worktree and branch are deleted; one with changes or commits is kept and reported. Shells out to =git=. Verified in a pty against a real repo.

** DONE TUI: multi-line input and vim editing
Shift+Enter (also Alt+Enter, Ctrl+J) inserts a newline; the prompt box grows to 6 rows. Shift+Enter needs a terminal with the kitty keyboard protocol (kitty, WezTerm, Ghostty, iTerm2, recent Alacritty); elsewhere use Alt+Enter or Ctrl+J.
The prompt is now an =Editor= (=src/editor.rs=, hand-rolled, no ui deps) with a cursor. Normal mode edits it vim-style: =h l j k 0 ^ $ w b e gg G=, operators =d c y= + motion (doubled for lines), =x X D C s S r=, =i a I A o O=, =p P=, counts, =u= / =C-r=. Unit-tested; not driven in a real terminal yet. Click does not place the cursor.
** DONE TUI: bracketed paste
