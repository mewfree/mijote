#+title: mijote – Project Tasks
#+description: TUI orchestrator for existing coding-agent subscriptions

* Decisions

** DONE Orchestrator, not a harness
Reusing subscriptions means driving the official CLIs. Writing our own agent loop would force API-key billing and lose vendor tuning. We own the UX, sessions and worktrees; vendors own the loop.

** DONE Antigravity entry point
Official =agy= CLI ships a native ACP stdio server (=agy acp=), configured with =Install::None= in =src/agent/mod.rs= (no third-party adapter). Verified end to end with =mijote ask antigravity= and =session/set_config_option= model switching.

** DONE Remove Gemini CLI backend
Removed the =gemini= entry from =agent::KNOWN= in =src/agent/mod.rs= now that Antigravity (=agy acp=) is supported. Updated =readme.org=, =demo-setup.sh=, and the switcher test in =src/app.rs=.

* Tasks

=src/agent/acp.rs=: spawn, =initialize=, =session/new=, =session/prompt= with streamed =session/update= events and =session/request_permission= callbacks. Tested against a scripted fake agent; real handshake verified against =gemini --experimental-acp=. Try it with =mijote ask <agent> "<prompt>"=.

** TODO ACP: cancel, load/resume, set_mode

** DONE Managed adapter install
=src/agent/install.rs=: resolves an agent binary from PATH or =$MIJOTE_HOME= (default =~/.local/share/mijote=), otherwise =npm install --prefix= of a pinned adapter version (claude: =@agentclientprotocol/claude-agent-acp=, codex: =@agentclientprotocol/codex-acp=). =mijote install <agent>= does it explicitly; =mijote ask= does it on first use. Requires Node/npm. Verified: =mijote ask claude= completes a real turn.
** TODO Verify codex end to end
Exercise =codex-acp= (needs Codex login or API key).
** TODO Adapter updates
Pinned versions drift. Add =mijote update= (or a version check) and decide how to handle a missing Node (download a managed runtime?).
** TODO Stream-JSON fallback transport (only if an agent lacks an ACP adapter)
For CLIs without ACP (=claude -p --output-format stream-json=, =codex exec --json=).
** DONE Session persistence
=src/store.rs=: one JSON record per session under =$MIJOTE_HOME/sessions/= (agent, cwd, worktree, transcript), written atomically after each prompt and turn end and on quit. On start, records for the current directory are reopened with a fresh agent behind the old transcript (a notice says the agent does not remember it). Closing with =d= deletes the record; quitting keeps it. A missing worktree falls back to the current directory.
** TODO Resume agent context on restore
Persisted sessions restart the agent cold. Store the ACP session id and use =session/load= when the agent advertises =loadSession=. Also: restored sessions spawn their agents eagerly at startup; make that lazy (first prompt) so reopening many sessions does not launch many CLIs.
** DONE Model selection
=ModelState= in =src/agent/acp.rs= reads the model from =session/new=: the =configOptions= entry with category =model= (what =claude-agent-acp= sends; switched with =session/set_config_option=, announced by =config_option_update=), falling back to the older =models= field (=session/set_model=, =current_model_update=). The header shows the current model, =M= (normal mode, between turns) opens a picker, and each change is logged as a transcript notice. The choice is stored in the session record and re-applied on restore. Agents that advertise no models get a "does not offer model selection" message. Unit-tested against fake agents; the config-option shape was taken from the pinned =claude-agent-acp= source, not a live run. Codex and Gemini not checked.
** DONE Slash commands: /model
Insert-mode =/model= opens the model picker; =/model <name>= switches directly (id or display name, case-insensitive; unknown names list the choices). Handled locally in =App::slash_model= because =/model= is a terminal-UI command in Claude Code and not reliable to forward. Anything else, including =/models=, goes to the agent as a prompt.
** TODO Slash commands: agent-advertised
Parse =available_commands_update= (today =Event::Other=) so the agent's own commands can be listed and completed in the prompt box; =/model= should then appear alongside them.
** DONE Prompt: =@= file mentions
=src/files.rs= lists workspace files via =git ls-files= (falling back to a bounded directory walk outside git repos), fuzzy-matches queries, and expands =@path= / =@"path with spaces"= mentions into ACP =PromptBlock=s. Typing =@= in insert mode opens a floating autocomplete popup above the prompt box (=↑/↓= or =C-p/C-n= to move, =Tab=/=Enter= to insert, =Esc= to dismiss). =AcpClient::initialize= reads =agentCapabilities.promptCapabilities.embeddedContext= and =session.rs= / =mijote ask= send small UTF-8 files as ACP =resource= blocks when supported, falling back to =resource_link= for larger/binary files or agents without =embeddedContext= (leaving non-existent =@tokens= untouched as plain text).
** TODO Session model: tasks and history browser
Task -> session(s) grouping, and a way to list and reopen records saved from other directories or closed sessions.
** DONE Git worktree per task
=src/worktree.rs=: each session gets branch =mijote/<agent>-<n>= in a worktree under =$MIJOTE_HOME/worktrees/<repo>/=, based on the repo's =HEAD=. Outside a git repo (or with no commits) the session falls back to the current directory with a notice. On =d= close or quit, an untouched worktree and branch are deleted; one with changes or commits is kept and reported. Shells out to =git=. Verified in a pty against a real repo.
** DONE Worktrees: optional
=n= opens the picker for an isolated session (worktree, as before); =N= opens it for a session that runs directly in the current directory and branch (no worktree, nothing to clean up). Picker title says which. Still TODO: a config default once =src/config.rs= exists.
** TODO Worktrees: review and merge flow
Show the session branch's diff/commits in the TUI; actions to merge, cherry-pick, open a PR, or discard. Today kept branches are only reported on close.
** TODO Worktrees: start from the dirty tree (optional)
Worktrees branch from =HEAD=, so uncommitted work in the main checkout is invisible to the agent. Offer =git stash create= as the base, or warn when the main tree is dirty.
** TODO Worktrees: crash cleanup and hung agents
A crashed mijote leaves worktrees behind (=mijote cleanup= / =git worktree prune=). Closing waits for the agent thread; a hung agent keeps its worktree (safe, but never reported).
** DONE TUI shell (ratatui)
Sidebar of sessions, transcript pane, prompt line, permission modal, new-session picker (=n=). One worker thread per session owns its ACP client; =session/cancel= goes through a =CancelHandle= so it works mid-turn. Files: =src/app.rs= (state, keys), =src/ui/mod.rs= (rendering), =src/session.rs= (model + worker). Verified in a pty against a real Claude turn.
** DONE TUI: visual redesign
=src/ui/mod.rs= only. Palette constants (ANSI accent, one 256-colour grey); sidebar of two-row session cards (status glyph, agent, branch or live state, accent bar on the selection) with a wordmark and key footer; header strip with agent, branch and status; transcript without a box, hand-wrapped so every line keeps its gutter (user =▎=, thoughts =┊=, code fences =▏=, tool calls =✓ ✗ ○= grouped without gaps); rounded prompt box with placeholder; NORMAL/INSERT/PICK badge and bold-key hints in the status bar; rounded modals with hints on the bottom edge; welcome screen. =locate= follows the new geometry (cards are 2 rows, 2-row head).
** DONE TUI: floating session switcher
The always-on sidebar is gone; the transcript uses the full width. =s= or =Tab= (normal mode) opens a floating list of sessions (status glyph, agent, branch or live state); =j/k=, =1-9=, =Enter= switch, =Esc= cancels. The header shows a badge when a background session needs permission. Mouse hit-testing lost its session region. Supersedes the sidebar parts of the redesign and of the "sidebar labels and attention" / "rename" tasks below, which now apply to the switcher.
** DONE TUI: multi-line input and vim editing
Shift+Enter (also Alt+Enter, Ctrl+J) inserts a newline; the prompt box grows to 6 rows. Shift+Enter needs a terminal with the kitty keyboard protocol (kitty, WezTerm, Ghostty, iTerm2, recent Alacritty); elsewhere use Alt+Enter or Ctrl+J.
The prompt is now an =Editor= (=src/editor.rs=, hand-rolled, no ui deps) with a cursor. Normal mode edits it vim-style: =h l j k 0 ^ $ w b e gg G=, operators =d c y= + motion (doubled for lines), =x X D C s S r=, =i a I A o O=, =p P=, counts, =u= / =C-r=. Insert mode: arrows, Home/End, Delete, =C-w=, =C-u=. Not covered: text objects, =f/t=, dot repeat, visual mode, named registers.
App-level commands moved behind a leader key (=Space= in normal mode, =C-a= in normal or insert mode): =n N d M s j/k g/G m q=, so =dd= in the prompt can no longer close the session. With no session open there is no prompt, so those keys work without the leader. =Tab= (switcher), =Enter= (insert), PgUp/PgDn stay direct. Arrows move the prompt cursor; use leader + arrows or PgUp/PgDn to scroll the transcript.
Unit-tested; not driven in a real terminal yet. Click does not place the cursor.
** DONE TUI: bracketed paste
Bracketed paste is enabled in =main.rs=; =App::handle_paste= inserts the text at the cursor in insert mode (ignored elsewhere), so pasted newlines no longer submit the prompt. CRLF/CR become =\n=, tabs four spaces, other control chars are dropped. Pastes over 3 lines or 500 chars show as =[Pasted text #1 +12 lines]= and are expanded when the prompt is sent (an edited or deleted placeholder is left as typed). Not covered: image paste, pasted file paths, Normal-mode paste. Unit-tested; not driven in a real terminal.
** DONE TUI: markdown rendering
Agent messages render through =ui/markdown.rs= (pulldown-cmark): headings, bold/italic/strikethrough, inline and fenced code, bullet/numbered/task lists, block quotes, rules, links (destination shown after the text). Wrapped to the transcript width with hanging indents. Tables and syntax highlighting are not handled; tables show as plain text.
** DONE TUI: improve markdown link rendering
=src/ui/markdown.rs= no longer dumps noisy inline =(url)= suffixes after links. Web links with distinct labels get deduplicated compact =[n]= markers and a wrapped reference list at the bottom of the message (while bare/matching URLs emit no redundant footnote); =file://= links strip raw =file://= paths, format =#L10-L20= fragments as compact =:10-20= suffixes, and relativize references against the session working directory. Empty link labels, inline code inside links, and nested image links are handled cleanly, and =src/ui/mod.rs= + =src/main.rs= overlay clickable OSC 8 terminal hyperlinks (=write_osc8_links=) over visible transcript links while preserving cell styles and suppressing overlays when a modal is open.
** DONE TUI: tool call detail
=ToolContent= in =src/agent/acp.rs= parses text, terminal output, and diff blocks from ACP =tool_call= and =tool_call_update= (=content= and optional =title=). =Entry::Tool= in =src/session.rs= stores =detail= with =#[serde(default)]= so older session records stay readable, and =tool_call_update= replaces =detail= when non-empty while preserving it across status-only updates. =src/ui/mod.rs= renders tool diffs (path header, compact line diff in red/green/dim, capped at 16 lines) and text output (dim =│= gutter, capped at 10 lines) beneath tool rows with =▾=/=▸= indicators; =leader + t= in =src/app.rs= toggles =show_tool_details= (expanded by default).
** DONE TUI: rename sessions, show worktree state
=leader + r= (or =r= inside the session switcher to rename the highlighted session) opens a rename modal (=Mode::Rename=); labels persist in =store::Record= (backwards-compatible via =#[serde(default)]=) and empty input clears the custom name. =Session::refresh_worktree_state= tracks live dirty (=*=) and ahead (=+N=) counts from =Worktree::state()=, refreshed on spawn/restore, turn completion, switcher open, and session switch, and displayed beside the branch in both the header and the switcher.
** DONE TUI: mouse mode
Mouse capture is on by default: wheel scrolls the transcript, a click on a sidebar row selects that session, a click on the prompt box enters insert mode. =m= (normal mode) toggles capture off so the terminal's own text selection works. Hit-testing lives in =ui::locate= beside the layout; modals (picker, permission, confirm) ignore the mouse.
** DONE TUI: mouse text selection and copy
Left-drag over the transcript highlights text (reverse video) and copies it on release. Positions are kept in transcript content coordinates (=src/selection.rs=), so the highlight follows the text when scrolling; dragging past the top or bottom edge scrolls. A click or key press clears it. Copy goes through =src/clipboard.rs=: OSC 52 (works over ssh in iTerm2, kitty, WezTerm, Ghostty, tmux with =set-clipboard on=) plus =pbcopy= on macOS for Terminal.app. Selection is by line, so gutter glyphs (=▎=, =┊=) are copied with the text. Not verified in a live terminal.
** DONE TUI: transcript scrolling and search
PgUp/PgDn (also in insert mode), =g=/Home top, =G=/End follow, wheel, and half-page =Ctrl-u=/=Ctrl-d= scrolling (in Normal mode with a session open and no modal, or behind the leader key; =Ctrl-d= still quits everywhere else — Insert mode, modals, and with no sessions open). =/= (and leader + =/=) opens live case-insensitive transcript search (=Mode::Search=) with highlighted matches, status-bar match counter, =Enter= to keep highlights and return to Normal mode, =n=/=N= to cycle matches and scroll them into view, and =Esc= to clear.
** DONE TUI: start on a new session by default
On startup, mijote no longer auto-restores saved sessions; instead it immediately opens a new session in the current directory (no worktree) using the first installed backend (=agent::default_agent=, falling back to Claude Code). Pass =--resume= / =-r= to reopen saved sessions for the current directory.
** DONE TUI: default to agent used in previous conversation
On startup, =App::open_default_session= picks the agent used in the previous conversation instead of always falling back to the first installed backend (Claude Code). =Store::save_last_agent= records the agent id in =$MIJOTE_HOME/sessions/last-agent= whenever a prompt is sent (so closing a session with =d= or quitting with multiple sessions does not lose it); =Store::last_agent= reads that file, falls back to the newest saved session record across all directories for existing users, and =App::default_agent= falls back to =agent::default_agent= if none is recorded or the agent is no longer known.
** DONE TUI: open the picker when there is no session
When all sessions are closed (or =--resume= finds none): (1) =i=/=Enter= in normal mode opens the new-session picker in the current directory (=open_picker(false)=) instead of being a no-op (and closing the last session returns to normal mode); (2) =open_picker= (via =open_picker_with=) spawns the single candidate agent directly and skips =Mode::Picker= when only one agent is available. Updated the welcome screen, prompt placeholder, and status bar hints to advertise =i= / =Enter=.
** DONE TUI: Ctrl-D quits
=Ctrl-D= sets =should_quit= from Insert mode, modals (permission/confirm/picker/model/switcher/search), and when no sessions are open (same path as idle =Ctrl-C=). Resolved with =Ctrl-u/d= half-page scroll: in Normal mode with a session open and no modal (or after the leader), =Ctrl-d= scrolls down half a page.
** DONE TUI: working indicator
Running turns show an animated spinner in the sidebar and a trailing =working… 12s= line in the transcript (=Session.turn_started=); a pending permission shows =waiting for your permission=. A long silent turn no longer looks hung.
** DONE TUI: confirm destructive actions
=q= (while any agent is mid-turn) and =d= (running or non-empty session) open a y/n confirm modal. Normal-mode =Esc= no longer cancels the turn; use =Ctrl-C=. =Ctrl-D= still quits immediately.
** DONE TUI: context-aware status bar
Key hints depend on state (idle, running, scrolled, insert, confirm); cwd is shown only when it fits.
** DONE TUI: sidebar labels and attention
Applied to the floating session switcher and header: every session shows its custom label (=<label> · <agent>=) or worktree branch alongside the agent name regardless of run state so parallel sessions are always distinguishable. Background =TurnDone= sets =Session.attention= (cleared when switching to the session) and both background =TurnDone= and =Permission= ring the terminal bell (=\x07= via =App.pending_bell=). The header shows high-contrast =◆ N waiting= and =★ N done · s switch= badges; the switcher highlights =◆ needs permission= and =★ done= rows.
** DONE TUI: richer permission modal
=PermissionRequest= in =src/agent/acp.rs= now parses =toolCall.kind=, =rawInput= commands/paths, =locations= (with line numbers), =content= diffs (=PermissionDiff=), and fallback preview text. =App::handle_permission_key= adds =a= (prefer =allow_once=, else =allow*=) and =r= (prefer =reject_once=, else =reject*=, else cancel turn) alongside =1-9= and =Esc=. =render_permission= displays the kind badge, locations, =$ command= lines, colorized/capped diff previews, deduplicated human-readable option labels, =[a]=/=[r]= badges, and dynamic modal sizing.

** DONE TUI: persistent notices and help overlay
Status-bar notices now carry a 4-second TTL (=Notice= with =App::set_message=, =App::message=, and =App::tick= called from the event loop) instead of being wiped on the next key press or paste, staying visible until expired or replaced. =?= in normal mode (with no pending vim operator) and =leader + ?= from normal or insert mode open a =Mode::Help= rounded modal listing vim prompt, leader command, and session/scroll keys (=Esc=, =q=, or =?= closes it); status bar hints include =? help= and show a =HELP= badge while open.
